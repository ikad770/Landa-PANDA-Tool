# Landa PANDA Tool — Pixel-Perfect Visual Prototype

This standalone prototype is built to visually match the approved Landa PANDA Tool mockups as closely as possible.

## How to run

Open `index.html` directly in the browser.

No npm, no Vite, no build step, no dependencies.

## Screens

- Service Radar overview
- BSS Blanket System drill-down

## Interactions

- Click the BSS hotspot on the machine or the "Open Drill-Down" area to open the drill-down screen.
- Click "View Machine Overview" / mini machine area to go back.
- Click component hotspots in drill-down to show component focus feedback.
- Keyboard: `1` overview, `2` drill-down, `Esc` overview.

## Notes

This version prioritizes exact visual fidelity to the approved mockups. The next engineering step is to progressively replace screenshot-backed sections with native React/SVG components while preserving the same visual design system.
